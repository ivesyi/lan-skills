# CHECKLISTS —— 自检清单

执行方式：能开独立 agent，就让它拿"工作区路径 + 本文件"逐项核查并汇报
pass/fail + 证据；不能，就自己逐项过、**每项写一行结论**，不许目测放行。
铁律：**先把 fail 项修完，再汇报 / 再推进**。

---

## §A 逐图质检（每出一张图，当场过）

不要攒到全部生成完再统一看——早一张发现问题，后面几张的提示词能一起改对。

- [ ] **图上没有任何具体人名**（便签、桌牌、名牌、黑板上都查一遍）
- [ ] **图上没有任何英文字样**（含 IP 自己的英文名）
- [ ] 中文标注 5~8 处封顶，每处 2~6 个字，没有错字、没有长句
- [ ] 图上没有文章里不存在的数字、比例、榜单
- [ ] 画幅比例对（正文插画横版；封面按发布端要求的比例）
- [ ] IP 是画面里做核心动作的那个，不是站在旁边的装饰
- [ ] IP 形象与设定一致（发型、眼镜、穿着没有漂移）——拿设定图对一眼
- [ ] 一张图只讲一个结构；画面不过满，主体留得住白
- [ ] 这张图和它要放的那段正文说的是同一件事
- [ ] 不合格 → 改 `prompts/pN.txt` 里的约束再跑；**旧图挪进 `images/v1/`，不删**

（更细的画风判据在对应兄弟包的 qa-checklist，需要时打开对照。）

**打不开图片文件时**：这张清单自己过不了，**不许跳过、不许目测放行**。
把本节原样附进给用户的成品汇报里，请他对着看一眼（重点前四条），
并在交付说明里写明"图这次没经过我的检查"。

## §B 成品自检（Checkpoint 成品之前）

- [ ] 正文里每个 `【图N】` 都有对应的图，图也都有对应的位置，**编号和位置一一对上**
- [ ] 正文改动之后，配图清单里的图号和插入位置已经顺过一遍
- [ ] 文章是第一人称、有具体现场细节开场、只讲一件事
- [ ] 结尾有三个能直接拿去用的动作，每个都具体到场合/产出/周期
- [ ] 有作者自省的那一段（作者不站在审判位置上）
- [ ] 机制部分写的是"互相强化的循环"，没有"因为…所以…"的因果断言
- [ ] 内容源里弃权、没证据的部分，文章里没有被补成结论
- [ ] 标题给了 3 个候选，且三个角度不同（不是同一句的三种改写）
- [ ] 正文里没有外部链接
- [ ] 对着 `CRAFT.md` §一眼假清单逐条排除过（文章 5 条 + 图 5 条）

## §C 交付前扫描（推草稿之前）

- [ ] **隐私扫描**：正文、标题、摘要、图上、文件名里，都没有真实校名和人名；
  同一个人全文用的是同一个代称
- [ ] **工作区扫描**：`.local/<文章代号>/` 确实在 git 忽略范围内，未匿名化的
  原始材料没有被复制到会进版本库的位置
- [ ] **封面规格**：已按 `../wechat-draft-publisher/` 当前文档核过比例与尺寸；
  推稿命令里带的是主封面那一张（方封面另行交付给用户）
- [ ] **发布边界**：确认这次动作只到草稿箱；交付话术里没有"已发布""已推送给读者"
  之类的说法
- [ ] **AI 标识**：图上如果带着平台自动加的 AI 生成标识，交付说明里已如实写明
  位置和处理建议
- [ ] 交付说明五项齐全：草稿在哪 / 发布由谁点 / 图有几张各放哪 / AI 标识 /
  还没做完的部分
- [ ] 模板占位符清零：`article.md`、`DELIVERY.md` 里没有残留的〔…〕/ <…> 占位符
