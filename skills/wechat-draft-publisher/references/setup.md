# 首次配置：从零到能发草稿

三件事：填凭据、加 IP 白名单、跑通自检。顺序不能反——白名单要用自检报出来的
地址才填得准。

## 一、填凭据

```bash
cd .codex/skills/wechat-draft-publisher
node scripts/doctor.mjs --init
```

会在 `~/.config/wechat-draft/config.yaml` 建一个模板（600 权限）。

打开 `mp.weixin.qq.com` 登录公众号，左侧菜单拉到最下面：

**设置与开发 → 开发 → 基本配置**

页面第一块叫「公众号开发信息」，里面：

- **开发者ID(AppID)**：`wx` 开头的 18 位，直接复制。
  （别拿错成「原始ID」，那个是 `gh_` 开头的，不是同一个东西。）
- **开发者密码(AppSecret)**：默认是打码的，看不到原文。点右边「重置」，
  管理员扫码确认，新密码会弹出来——**只显示这一次**，关掉页面就再也拿不到，
  只能再重置一次。所以看到就马上粘进配置文件。

填完长这样：

```yaml
wechat:
  appid: wx????????????????
  secret: ????????????????????????????????
```

### 关于重置 AppSecret

重置会让旧密码**立刻失效**。如果这个公众号还有别的系统在调接口（第三方排版
工具、CRM、自建服务），它们会一起挂掉，得同步换成新的。

如果想不起来有什么在用，那基本就是没有。

### 凭据放哪

按优先级找，先找到先用：

| 位置 | 什么时候用 |
|---|---|
| `$WECHAT_DRAFT_CONFIG` | 显式指定，临时覆盖 |
| `<项目根>/.local/wechat-draft.yaml` | 只想给这个项目单独配一个号 |
| `~/.config/wechat-draft/config.yaml` | 默认，跨项目共用 |

三个位置都在版本库之外。这个项目是公开仓库，**AppSecret 进了 git 就等于公开
了**，只能重置补救。

## 二、加 IP 白名单

微信只让白名单里的地址调接口。

### 不要猜 IP

不要用 `ipinfo.io`、`ipify` 或者路由器页面上看到的地址。有代理、有 NAT 的
时候，那些地址跟微信实际看到的**不是同一个**。本机实测过：查询服务显示
`103.151.173.97`，微信看到的却是 `183.193.17.46`——填前者永远不会通。

### 正确做法

直接跑自检，让微信自己说：

```bash
node scripts/doctor.mjs
```

```
❌ IP 不在白名单（错误码 40164）
   微信看到这台机器的地址是：183.193.17.46
```

这个地址就是要填的。回到「设置与开发 → 基本配置」，往下滚到「IP白名单」：

编辑 → 填地址 → **确定** → **保存**

两段式的，中间还会弹管理员扫码。少走一步就等于没加，但页面看着像加上了。

### 加完要等

**微信白名单大约 3 分钟才生效，不是即时的。** 加完马上测必然还是 40164，很
容易误判成没加成功、反复重加。

让它自己等：

```bash
node scripts/doctor.mjs --watch
```

每分钟重试一次，通了就停。

### 还是不通

按这个顺序查：

1. **AppID 对不对。** 白名单加到别的公众号/小程序后台上，是最常见的原因。
   自检会打印当前配置的 AppID，跟后台那一页显示的对一下。
2. **保存走完没有。** 回后台刷新，看白名单列表里到底有没有那一行。
3. **地址填错。** 只认自检报出来的那个。

### 地址会变

家用宽带是动态地址，运营商重拨、换网络（热点、咖啡馆 Wi-Fi、开 VPN）都会
变，一变就又是 40164。补进白名单即可，能存多个（上限 30 个）。

要彻底免除这个麻烦，把发布放到固定 IP 的机器上跑（云服务器），白名单填一次
管到底。skill 的脚本可以整个拷到服务器上跑，配置文件同样放
`~/.config/wechat-draft/config.yaml`。

## 三、确认通了

```bash
node scripts/doctor.mjs
```

```
✅ 配置文件：/Users/…/.config/wechat-draft/config.yaml（user）
✅ AppID：wx????????????????
✅ AppSecret：已填写（32 位，不回显）
✅ 拿到 access_token —— 整条链路通了
```

到这一步就可以开始写文章了。
