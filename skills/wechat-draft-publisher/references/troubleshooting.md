# 错误码速查

微信接口的报错码。左边是碰到时最该做的事。

## 40164 — IP 不在白名单

```
invalid ip 183.193.17.46 ipv6 ::ffff:183.193.17.46, not in whitelist
```

报错里那个地址就是微信看到的真实来源，**填它**，不要用其他方式查到的地址。

去「设置与开发 → 基本配置 → IP白名单」加进去，确定 + 保存 + 管理员扫码。

然后**等 3 分钟**——白名单不是即时生效的。用 `node scripts/doctor.mjs --watch`
自动等，别手动反复重加。

等超过 5 分钟还不通，八成是白名单加到别的号上了，核对 AppID。

## 40125 / 40001 — AppSecret 不对

```
invalid appsecret
```

要么当初抄漏了，要么后来重置过——重置会让旧的立刻作废。

AppSecret 只在生成那一刻显示一次，没法回去查，只能重新生成：
「设置与开发 → 基本配置 → 开发者密码(AppSecret) → 重置」，扫码后立刻粘进配
置文件。

注意重置会连带弄挂其他在用这个公众号接口的系统。

## 40013 — AppID 无效

AppID 抄错了，或者用的是小程序/测试号的 ID。回后台核对。

## 45009 — 接口调用频率超限

微信对接口有日调用上限。等一等再试。如果是反复重试脚本撞上的，先停下来查
清楚根因，别继续撞。

## 44003 — 图文内容为空

正文渲染出来是空的。检查 Markdown 文件是不是空的，或者内容全被过滤掉了
（比如整篇只有一个被微信剥掉的标签）。

## 40007 — media_id 无效

封面素材传失败或者过期了。永久素材不会过期，临时素材 3 天就没了——封面必须
走永久素材（`material/add_material`），脚本里已经是这么做的。碰到这个码先看
封面上传那一步的报错。

## 图文创建成功，但后台看不到封面

封面必须是**永久素材**。用临时素材接口传的 media_id 建草稿能成功，但封面是
空的。

## 正文里的图片显示不出来

微信会过滤外链图片。正文的图必须先上传到微信换成 `mmbiz.qpic.cn` 的地址。
脚本默认会做这件事，除非加了 `--no-upload-images`（不推荐）。

## 排版在浏览器里正常，粘进微信就乱了

微信会剥掉 `<style>` 标签和 class 选择器。样式必须内联到每个元素上。
`convert` 命令已经用 `juice` 做了内联；如果是手写的 HTML 直接往里贴，就会
碰到这个问题。

## 连不上 api.weixin.qq.com

网络问题，不是配置问题。这台机器出不去外网，或者被代理拦了。
