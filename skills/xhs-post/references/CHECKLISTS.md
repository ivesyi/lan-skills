# CHECKLISTS —— 自检清单

执行方式：能开独立 agent 就让它拿「工作区路径 + 本文件」逐项核查并汇报
pass/fail + 证据；不能就自己逐项过、**每项写一行结论**，不许目测放行。
铁律：先修完 fail 项，再交付 / 再推进。

## A. 文案自检（Phase 2 完成时）

- [ ] 标题候选 3~5 个，每个 ≤20 字，且每个都标注了钩子是什么
- [ ] 全篇只讲一个核心判断；能独立扫读的点在 3~7 个之间
- [ ] 正文是**纯文本**：通读一遍，没有 `**`、`#`、`-`、`>`、`|` 这类
  markdown 符号（有一个就是 fail——用户要整段复制直接贴）
- [ ] 第一人称、口语化分段；随手挑 2 段念出来，不像书面报告
- [ ] emoji 节制：不是每句一个；数一下总量，超过分段数就偏多了
- [ ] 话题标签 5~8 个
- [ ] 标题的承诺在正文里兑现（标题说几点，正文数得出几点）
- [ ] 对照 `CRAFT.md` §一眼假清单逐条排除
- [ ] 匿名化：无真实校名、人名、可识别的班级/项目/机构名
- [ ] 无行业黑话、框架名、缩写、内部代号、文件路径

## B. 卡片自检（每张图出完时）

**先打开 `../xhs-visual-cards/references/card-guidelines.md` §验收清单，
逐条对照**——那份是卡片本身的标准，以它的原文为准。
注意：那是一份**要人逐条看的清单，不是能跑的脚本**，别指望有个命令
帮你把图验了。

依赖包清单之外，本 skill 再加四条：

- [ ] 图上的中文**没有溢出、没有被裁切**、没有半个字贴边
- [ ] 图上**没有具体人名、没有英文**（署名、桌牌、标签、水印全算）
- [ ] 封面上的字和选定的标题对得上（标题改过就要重出封面）
- [ ] 是完整 3:4 竖图，文件落在工作区 `cards/`，命名带顺序号
  （`01-cover.png`、`02-…`）

fail 的当场重出，不要攒到最后一起返工。

## C. 交付前扫描（Phase 5 文档成稿后）

- [ ] **边界确认**：全程没有登录小红书、没有操作浏览器、没有调用任何
  发布/定时接口，产出止于飞书文档（这条是红线，逐项回想一遍再打勾）
- [ ] **隐私扫描**：文案 + 每张图上的字 + 图片说明，全部扫一遍人名校名
  机构名；工作区在 `.local/` 且未入 git
- [ ] 文案区块是**一整块可整段复制的纯文本**：中间没有插说明文字、
  没有 markdown 符号、没有残留的〔占位符〕
- [ ] 图片清单每一行都对得上实际文件：路径存在、顺序号连续、
  第 1 张是封面；清单里写的张数 = `cards/` 里的张数
- [ ] 缺件如实写明：没出成的图、没做的部分，写清缺什么和为什么，
  不拿别的东西（截图/拼图）冒充
- [ ] AI 生成这件事已在交付说明里注明
- [ ] 代定项已标出：用户说「你定」时我替他定了什么、理由是什么、
  怎么改回来
- [ ] 交付话术里明确写了「发布你自己点」
