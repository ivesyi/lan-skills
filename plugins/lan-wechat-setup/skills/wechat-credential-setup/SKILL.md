# 公众号账号设置

把公众号凭据配置做成顾问能独立完成的引导流程。

## 使用方式

当用户要首次设置、更换或检查公众号账号时，调用 `open_wechat_setup`，让 Desktop 显示设置表单。不要要求用户打开配置文件或执行终端命令。

表单内的保存动作由用户点击触发。保存工具会先向微信验证；验证成功后才替换本机长期配置。聊天中只汇报是否通过、需要加入白名单的 IP 或微信错误类型，不复述 AppSecret。

若当前客户端不能显示 MCP App 界面，先让 Agent 运行 `~/lan-skills/install.sh codex` 修复插件安装，并要求用户新开一个 Codex 任务。不要把手改 YAML 当作顾问的降级流程；非 Codex 客户端应明确说明暂不支持这个引导界面。

配置完成不等于授权发布。推送草稿前仍需获得用户对具体草稿的授权。
